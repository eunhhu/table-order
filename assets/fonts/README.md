# Noto Sans KR

NotoSansKR.ttf is the variable Noto Sans KR font distributed under the SIL Open Font License 1.1. The license is included in OFL.txt.

Source: https://github.com/google/fonts/tree/main/ofl/notosanskr

The QR card renderer converts this font's glyphs to vector paths before rasterizing at print resolution. It does not rely on fonts installed on the host.
